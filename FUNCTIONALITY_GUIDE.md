# Functionality guide

Start with [the Omneity skill](skills/omneity/SKILL.md).
Use [capability selection](skills/omneity/references/functionality-guide.md) to
route by task. Use [the endpoint inventory](skills/omneity/references/endpoints.md)
for current HTTP operations. Read [pricing](skills/omneity/references/pricing.md)
before estimating costs.

The skill uses one entrypoint with focused references. Keep API details in those
references and in [the OpenAPI contract](api/openapi.json).
